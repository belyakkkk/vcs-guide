Шпаргалка команд Git и SVN

Самые важные команды для ежедневной работы с системами контроля версий.

Основные команды Git

Команды Git
Команда Описание
git init Создать новый репозиторий в текущей папке
git clone URL Склонировать удалённый репозиторий
git status Показать состояние файлов
git add FILE Добавить файл в индекс (staging area)
git commit -m "сообщение" Зафиксировать изменения
git push Отправить коммиты на удалённый сервер
git pull Получить изменения с сервера
git branch Показать список веток
git checkout -b new-branch Создать новую ветку и переключиться на неё
git merge branch Слить указанную ветку в текущую

Основные команды SVN

Команды SVN
Команда Описание
svn checkout URL Получить рабочую копию из репозитория
svn update Обновить рабочую копию с сервера
svn status Показать состояние рабочей копии
svn add FILE Добавить новый файл под версионный контроль
svn commit -m "сообщение" Зафиксировать изменения на сервере
svn copy URL URL Создать ветку или метку
svn merge URL Слить изменения из другой ветки
svn revert FILE Отменить локальные изменения в файле
