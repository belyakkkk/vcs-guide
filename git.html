Git — распределённая система контроля версий

Git — это распределённая система контроля версий, созданная Линусом Торвальдсом в 2005 году для разработки ядра Linux. Сегодня Git — самый популярный инструмент контроля версий в мире.

Ключевые особенности Git

  • Распределённость: у каждого разработчика есть полная копия репозитория с историей
  • Скорость: большинство операций выполняется локально, без обращения к серверу
  • Ветвление: создание ветки — мгновенная операция
  • Целостность: каждый коммит защищён хешем SHA-1

Основные понятия

Репозиторий
Хранилище всех файлов проекта и истории их изменений
Коммит (commit)
Зафиксированное состояние проекта на определённый момент
Ветка (branch)
Независимая линия разработки
Удалённый репозиторий (remote)
Копия репозитория на сервере (GitHub, GitLab, Bitbucket)

Популярные платформы для Git

  • GitHub — крупнейшая платформа
  • GitLab — с встроенным CI/CD
  • Bitbucket — от Atlassian
