# VCS Guide — учебный проект

 **Live-сайт:** https://belyakkkk.github.io/vcs-guide/

Тема проекта
Системы контроля версий (Git, SVN).

Использованный CSS-фреймворк
**Marx** — classless CSS framework (https://mblode.github.io/marx/).

 Технологии
- HTML5 (семантическая разметка)
- CSS3 (кастомные стили в `css/custom.css`)
- Marx CSS (v5)
- JavaScript (нативный, `js/menu.js` — бургер-меню)
- Git + GitHub Pages

 Структура проекта
- "index.html" — Главная
- "history.html" — История VCS
- "git.html" — О Git
- "svn.html" — О SVN
- "comparison.html" — Сравнение Git и SVN
- "commands.html" — Шпаргалка команд
- "workflow.html" — Рабочий процесс
- "video.html" — Видео
- "contact.html" — Контакты
